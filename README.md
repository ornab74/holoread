# HoloRead

HoloRead is a privacy-first Flutter reading intelligence system with an encrypted local SQLite database, explainable book recommendations, adaptive reminders, reading analytics, and bidirectional Google Sheets synchronization.

## Included

- Holographic glassmorphic responsive interface
- Android, iOS, Linux, Windows, and macOS host bootstrap script
- SQLCipher-backed SQLite selected through the `sqlite3` native-assets hook
- 256-bit random database key stored with platform secure storage
- Offline-first book and reading-session repository
- Google Sign-In 7 authorization flow
- Google Sheets schema validation and repair
- Bidirectional synchronization with versions, hashing, and conflict preservation
- Mechanis explainable recommendation engine
- Adaptive reminder engine using reading time, pace, priority, and quiet hours
- Local notifications
- Reading telemetry
- Low-power, reduced-motion, and OLED modes
- Unit tests for recommendations and reminders

## Requirements

- Flutter 3.44.0 or later
- Dart 3.12.0 or later
- A Google Cloud project for Sheets synchronization
- Android API 23 or later because secure storage uses modern Android cryptography

## Start

The archive contains the complete Dart/Flutter application source. Generate the standard platform host projects on the machine where you build it:

```bash
chmod +x tool/bootstrap.sh
./tool/bootstrap.sh
```

Then run:

```bash
flutter run -d linux
# or
flutter run -d android
```

The bootstrap command preserves `lib`, `assets`, `test`, and project configuration while generating the native host folders.


## GitHub Actions builds

Every push and pull request to `main` runs `.github/workflows/build.yml`. The workflow analyzes/tests the project and builds downloadable artifacts for:

- Android: release APK and AAB
- Linux: x64 release bundle (`tar.gz`)
- Windows: x64 release bundle (`zip`)
- iOS: unsigned release `.app` archive for CI validation
- macOS: release `.app` archive

iOS App Store distribution still requires Apple signing certificates and provisioning profiles. The CI artifact is intentionally unsigned.

## Google OAuth build variables

Public OAuth client identifiers can be passed at build time:

```bash
flutter run \
  --dart-define=GOOGLE_OAUTH_CLIENT_ID=YOUR_CLIENT_ID \
  --dart-define=GOOGLE_OAUTH_SERVER_CLIENT_ID=YOUR_SERVER_CLIENT_ID \
  --dart-define=DEFAULT_SPREADSHEET_ID=OPTIONAL_SHEET_ID
```

Never place a Google OAuth client secret or service-account JSON inside a Flutter application.

See [docs/GOOGLE_SHEETS_SETUP.md](docs/GOOGLE_SHEETS_SETUP.md).

## Encrypted database

`pubspec.yaml` selects SQLCipher for `package:sqlite3`:

```yaml
hooks:
  user_defines:
    sqlite3:
      source: sqlcipher
```

At first launch, HoloRead creates a cryptographically random 32-byte key and stores it with `flutter_secure_storage`. The database is opened with that key before any schema operation. Initialization fails closed when the SQLCipher pragma is unavailable.

## Google Sheets format

A template is included at:

```text
assets/templates/holoread_books.csv
```

The app creates or repairs a sheet named `Books`, then maintains stable UUIDs and sync versions. The encrypted local database remains the primary source of truth.

## Important platform notes

- Google Sign-In supports Android, iOS, macOS, and web directly. Linux and Windows require a separate desktop OAuth broker or backend-assisted authorization before production deployment.
- Linux desktop notification servers do not provide a universal scheduling API. HoloRead catches unsupported scheduling failures instead of pretending a reminder was scheduled.
- A web build needs a separate SQLite3 Multiple Ciphers worker and HTTPS secure-storage implementation; it is intentionally not generated by the supplied bootstrap script.

## Troubleshooting dependency resolution

HoloRead uses `flutter_local_notifications ^22.2.0`, which requires `timezone ^0.11.0` or newer. The project pins `timezone ^0.11.1`. After updating an older copy, run:

```bash
flutter clean
rm -f pubspec.lock
flutter pub get
```
